# 上理日历 · 上海理工大学 2026—2027 学年日历

一个纯前端的日历网站（新粗野主义风格），帮你盯住当天的校园事宜、官方放假和重要节点。
支持手机安装为 App（PWA），可分享给同学使用；**非官方个人工具，放假与活动以学校最新通知为准**。

## 打开方式

用 Chrome 或 Edge 直接双击打开 `index.html` 即可，无需安装、无后端，数据保存在浏览器本地。

## 功能

- **今日条**：当天日期、星期、学期进度、今日事宜数量、距下一次放假的倒计时。
- **月历**：完整月视图，周一开头；假期区间内的每一天都标红，**包括落在周六、周日的日期**（如 2026 年中秋的 9/26、9/27，国庆的 10/3、10/4，2027 年劳动节 5/1）；不在假期内的普通周末保持灰色。
- **当日面板**：选中任意日期查看官方安排；官方事件可一键开启/关闭提醒；可添加个人事项（保存到 localStorage）。
- **接下来 5 件事**：从今天起的最近安排，点击可跳转。
- **放假刻度尺**：整个学年一格一天，红色=工作日放假、黄色=调休补课、深灰=周末、米白=普通工作日，悬停查看日期。
- **学期安排**：第一、二学期的短学期/理论教学周/考试周/寒假/暑假区间。
- **浏览器提醒**：点击“开启提醒”授权后，打开页面当天有已开启提醒的事项会弹系统通知，站内也会始终显示 Toast。
- **实时更新**：每天自动检查上海理工大学官网通知公告、教务处教学运行通知、体育教学部信息公告（含体测安排），并尽力检索微信公众号「上海理工大学体育教学部」；发现新事件会自动并入日历并用提示告知。

## 实时更新怎么用

- **桌面快捷方式**（推荐）：双击桌面「上理日历」，会自动启动本地同步服务并用 Edge 应用窗口打开日历；页面打开时自动检查一次，之后每 30 分钟复查一次，状态显示在顶栏（“今日 xx:xx 已检查”）。
- **纯本地打开**：直接双击 `index.html` 也能用，自动抓取的事件会随 `js/live-events.js` 载入；但没有本地服务时不会自动联网检查（顶栏会显示“更新服务未启动”，点“检查更新”会给出提示）。
- **每日定时抓取**：以管理员身份运行 `tools/install-daily-task.ps1`，会创建计划任务，每天 09:00 自动运行 `tools/update-events.js` 抓取新事件。
- **手动更新**：`node tools/update-events.js`；导入某篇公众号/官网文章：`node tools/update-events.js --url "文章链接"`。
- **本地服务命令**：`node server.js`（默认 http://127.0.0.1:3030）。

自动抓取的事件带“自动抓取”来源标注和原文链接，与内置官方事件按“日期+标题/主题词”去重；明显无关的通知（招标、采购、科研申报指南等）会被过滤。

## 手机端（PWA）与部署

- **手机安装**：把站点地址在 Android Chrome 中打开，点浏览器菜单 →“安装应用/添加到主屏”，之后以独立窗口打开，支持离线查看（Service Worker 缓存外壳与已载入事件）。
- **个人数据**：个人事项与提醒开关只存在各自设备的浏览器本地，不跨设备、不上传；分享链接给别人不会泄露你的私人数据。
- **GitHub Pages 部署**（推荐，全程免费）：把本目录作为仓库根目录推送到 GitHub，`push` 到 `main` 后 `.github/workflows/pages.yml` 自动发布；仓库公开（免费套餐），地址形如 `https://用户名.github.io/仓库名/`。
- **云端每日自动更新**：`.github/workflows/daily-update.yml` 每天北京时间 08:30 运行 `tools/update-events.js`，抓取到新事件会自动提交并触发重新发布；也可在 GitHub Actions 页面手动触发（`workflow_dispatch`）。
- **合规说明**：抓取频率低（每天一次、每来源最多 8 条），只取公开公告的标题/日期/摘要与原文链接，不转载全文；更新器会先检查各源 `robots.txt`，禁止抓取的源自动跳过。

## 规则说明

- 放假标注规则：假期区间内的所有日期都标红，包括周六、周日；不在假期内的普通周末保持灰色。
- 2027 年元旦、清明、劳动节、端午的**假期安排**以国务院办公厅届时通知为准；校历高亮日期（含落在周末的日期）均会标注。
- 标注为“预计”的考试/报名时间以官方公告为准。
